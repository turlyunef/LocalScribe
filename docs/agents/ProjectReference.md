## Переменные окружения

Тесты и упаковка управляются переменными окружения; без них соответствующие тесты пропускаются, поэтому число пропусков в полном прогоне может расти.

| Переменная | Действие |
| --- | --- |
| `LOCALSCRIBE_SIGN_IDENTITY` | подпись при упаковке `.app`; по умолчанию ad-hoc |
| `LOCALSCRIBE_GIGAAM_STATIC_ARCHIVE` | путь к статическому архиву runtime GigaAM. Упаковщик получает его из [build_gigaam_runtime.sh](../../scripts/build_gigaam_runtime.sh) |
| `LOCALSCRIBE_DND_APP` | путь к собранной и зарегистрированной в Launch Services `.app` для двух нативных DnD-тестов |
| `LOCALSCRIBE_SEARCH_BENCHMARK=1` | включает [RecordingSearchPerformanceTests](../../Tests/LocalScribeUITests/RecordingSearchPerformanceTests.swift) |
| `LOCALSCRIBE_DIAGRAM_FIXTURE_MODELS` + `LOCALSCRIBE_DIAGRAM_FIXTURE_IMAGES` | реальный VLM для DiagramVLMFixtureTests |
| `LOCALSCRIBE_DIARIZATION_FIXTURE_MODELS` + `LOCALSCRIBE_DIARIZATION_FIXTURE_WAV` | два модельных теста диаризации |
| `LOCALSCRIBE_AUDIO_MEMORY_BENCHMARK=1` | замер памяти планировщика аудио в AudioMemoryTests (синтетический PCM без ML inference) |
| `LOCALSCRIBE_PUML_OUT` | каталог образцов PlantUML для [DiagramPlantUMLSamplesTests](../../Tests/LocalScribeTests/DiagramExportTests.swift) |

Переменные технических ASR-проб (Whisper, Qwen3, VibeVoice: `LOCALSCRIBE_ASR_*`, `LOCALSCRIBE_QWEN_*`, `LOCALSCRIBE_VIBEVOICE_*`) перечислены в [ASRModels](../../docs/ASRModels.md) и [ASRMatrix](../../docs/ASRMatrix.md).

## Локальные конвенции и ловушки

- Импорт текстов: байты фиксируются один раз, BOM строго определяет UTF-8/UTF-16; без BOM конкурирующие декодирования UTF-8×Windows-1251 с разными текстами требуют подтверждения кодировки с предпросмотром.
- Дубли текстов сравниваются побайтово (BOM и кодировка значимы), отдельная копия получает новый UUID; предел показа и допуска — [AnonymizationInputLimit](../../Sources/LocalScribeCore/ModelTasks.swift), а `maximumCardBytes` — эффективный потолок карточки после base64/JSON: `importCard` отклоняет превышение до первой записи в `pending/` и `card.json`.
- Скачивание замораживает снимок правой версии до панели: `.md` сохраняет разметку, `.txt` — читаемый текст; выход всегда UTF-8 без BOM.
- Правки панелей карточки идут через `ScalarEdit`/[AnonymizationEditing](../../Sources/LocalScribeCore/AnonymizationEditing.swift): преобразование пар и предупреждений по правилам техдизайна, UTF-16 мост `TextUTF16Bridge` на границе редактора; документ карточки валидируется целиком.
- [AnonymizationRestoration](../../Sources/LocalScribeCore/AnonymizationRestoration.swift) восстанавливает значения по парам текущего сохранённого результата за один проход. Выбирается самое длинное точное совпадение на границах слова. Для подстановки с несколькими исходными значениями в выход попадает входной фрагмент.
- Вход, выход и диапазоны подсветки сохраняются через `AnonymizationCoordinator` в опциональном поле `restoration` того же `card.json` с ограничением размера JSON до записи. Новое обезличивание сохраняет прежнее восстановление. Импорт и вставка закрепляют ревизии обеих панелей обезличивания. Повтор берёт сохранённый вход и актуальные пары. При удалении карточки удаляются обе версии.
- [AnonymizationRestorationView](../../Sources/LocalScribe/AnonymizationRestorationView.swift) открывается внутри карточки после публикации результата. Импорт одного TXT или Markdown использует общие правила декодирования. Вставка читает текст из буфера. Оба действия сразу запускают восстановление.
- Копирование в обеих вкладках передаёт правый текст дословно, включая разметку Markdown. Экспорт фиксирует его до панели сохранения.
- В [AnonymizationDetailView](../../Sources/LocalScribe/AnonymizationDetailView.swift) предупреждения открываются кнопкой рядом со статусом. Переход к фрагменту возвращает во вкладку обезличивания и выделяет диапазон справа.
- [AnonymizationComparisonView](../../Sources/LocalScribe/AnonymizationComparisonView.swift) синхронизирует вертикальную прокрутку по относительной позиции в каждом документе. У двух вкладок сравнения отдельные переключатели, включённые по умолчанию.
- Задачу `ANONYMIZATION` и `anonymizationInputLimitBytes` ставит квалификация по [Qualification](../../docs/TextAnonymization/Qualification.md), одновременно в [models.lock.json](../../Resources/models.lock.json) и `VERIFIED_ANONYMIZATION` генератора. Техпроба — `--probe-anonymization <корень моделей> <входной.json> [выходной.json]`.
- Переключатель разделов остаётся в [ContentView](../../Sources/LocalScribe/ContentView.swift) при смене архива, чтобы выделение могло плавно перемещаться между вкладками. Системный `TabView` из настроек переносит вкладки в меню переполнения при ширине боковой панели.
- Под переключателем находится поиск, затем общий ряд действий из [SidebarSharedControls](../../Sources/LocalScribe/SidebarSharedControls.swift) с кнопками групп слева и действиями с файлами и записями справа.
- Интерфейс поддерживает русский и английский. Для новых подписей использовать `L10n.text` с русским ключом и переводом в [Interface.en.json](../../Sources/LocalScribeCore/Localization/Interface.en.json).
- Служебные предупреждения и ошибки из manifest/JSONL переводить при показе и экспорте через `L10n.message` и [Messages.en.json](../../Sources/LocalScribeCore/Localization/Messages.en.json).
- Сохранять машинные значения и пользовательский текст дословно. Описания разрешений macOS лежат в [en.lproj](../../Resources/en.lproj/InfoPlist.strings) и [ru.lproj](../../Resources/ru.lproj/InfoPlist.strings).
- [LocalScribeMain](../../Sources/LocalScribe/LocalScribeApp.swift) выбирает язык перед созданием UI, смена языка применяется после перезапуска. Тема приложения ([ApplicationTheme](../../Sources/LocalScribe/ApplicationTheme.swift)) применяется в `applicationWillFinishLaunching` до показа окон, смена темы в настройках действует сразу через `NSApp.appearance`, перезапуск не нужен.
- Идентификаторы английские, отступ 4 пробела. В [ContentView](../../Sources/LocalScribe/ContentView.swift) есть accessibility labels. Обязательных previews и UI snapshot-тестов нет.
- Ошибки для пользователя — `ScribeError.message`, показ — через единый [AppErrorHandler](../../Sources/LocalScribe/AppErrorHandler.swift), в том числе из настроек и редактора; неизвестные ошибки SDK worker заменяет нейтральным сообщением. Провал статусных записей манифеста (постановка в очередь, прерывание, сбой захвата/остановки) тоже репортится через `AppErrorHandler`, а не глотается `try?`.
- SDK stderr непрерывно дренируется без сохранения: он может содержать текст разговора. Диагностика с текстом разрешена только явному техническому probe, см. [Architecture](../../docs/Architecture.md). Трассировка ошибок SDK во всех трёх движках закрыта двойным замком: флаг `--trace-model-output` плюс техпроба (итоги — `sourceType == "technical-probe"` манифеста, схемы — вход `--probe-diagram`, обезличивание — `AnonymizationEngine.init(probing:)` квалификационного маршрута); продовые пути всегда выдают нейтральное сообщение.
- Модели публикуются из `.partial` только после проверки размеров и SHA-256 всего комплекта. Для сетевого прогресса сохранять явный `URLSessionDownloadTask` и привязку callback к requestID: образцы — [Models](../../Sources/LocalScribeCore/Models.swift) и [ModelDownloadClient](../../Sources/LocalScribe/ModelDownloadClient.swift).
- [SettingsWindow](../../Sources/LocalScribe/SettingsWindow.swift) хранит флаги, язык интерфейса, тему приложения, источники записи и выбор моделей в `SettingsDraft`. «ОК» проверяет совместимость выбранных моделей и сохраняет назначения перед применением флагов. «Отмена» отбрасывает черновик. Закрытие окна системной кнопкой при наличии правок запрашивает решение.
- Загрузка, импорт и удаление моделей выполняются сразу. UI показывает копируемый адрес текущего файла через тот же `ModelProfile.downloadURL`, что и XPC-загрузчик.
- Итоги, схемы и обезличивание выбирают модели независимо по `supportedTasks` и совместимости с Mac. ASR и диаризация остаются в `ModelLibrary`.
- [AnonymizationSettings](../../Sources/LocalScribeCore/AnonymizationSettings.swift) хранит назначения и дословный список типов данных в `anonymization/settings.json`.
- Миграция v1 переносит старый `SHARED` во все три назначения, а для `SEPARATE` использует действующие назначения итогов и схем из `ModelLibrary` при их наличии.
- Один установленный комплект доступен на всех совместимых вкладках с отметкой «Установлена». Установка не назначает модель другой задаче. [ModelPackageRegistry](../../Sources/LocalScribeCore/ModelPackages.swift) публикует готовность, выдаёт lease запущенному обезличиванию и пересчитывает затронутые назначения перед удалением. [ModelCatalog.verifiedModelFolder](../../Sources/LocalScribeCore/Models.swift) использует каталог для поиска другого профиля того же комплекта по совпадению путей, размеров и SHA-256.
- Перед загрузкой веса проверяются полностью, закреплённые ID и fingerprint задания сохраняются.

### Воспроизведение записей

- Плеер открывает завершённый архивный оригинал по первому действию пользователя. При выборе другой записи, закрытии последней карточки, удалении записи или завершении приложения освобождать AVPlayer, отменять открытие и игнорировать устаревшие события. Позицию публиковать через отдельный объект `RecordingPlayback` для плеера и текста расшифровки.
- Для AAC ADTS и Ogg/Opus (а также при сбое открытия или точной перемотки оригинала) [RecordingPlayback](../../Sources/LocalScribe/RecordingPlayback.swift) декодирует временный PCM CAF через локальный FFmpeg. Файловая подготовка и очистка идут вне MainActor. Удалять временный CAF при смене источника, ошибке и выходе. Архивный оригинал открывается на чтение.
- [Export](../../Sources/LocalScribeCore/Export.swift) даёт UI таймкоды и UTF-16 диапазоны реплик. [ResultPresentation](../../Sources/LocalScribe/ResultPresentation.swift) строит индекс вместе с рендерингом расшифровки вне MainActor. Подсветка сохраняет выделение текста, переключатель следования управляет автопрокруткой.
- Кнопки со стрелками по краям кнопок шаговой перемотки переходят к началам реплик и сохраняют паузу/воспроизведение. Назад из середины реплики возвращает к её началу; повторное нажатие у начала (допуск 50 мс) — к предыдущему отличающемуся таймкоду. Шаги перемотки — 5, 10, 15, 30 и 60 секунд.
- Модель после статуса расшифровки и в её экспорте определяется через `RecordingRepository.transcriptionModelID`: active run важнее pending, `transcriptSourceRunID` ведёт к исходному ASR через ручные правки/пересоздание итогов. Проверять UUID, источник и циклы; неизвестная модель не подменяется текущим выбором.
- Клик по реплике расшифровки перематывает с сохранением паузы или воспроизведения. Ссылка из итогов открывает расшифровку у реплики и запускает звук с её начала, если оригинал доступен. `AppModel.activateResultSegment` сверяет запись, вкладку и состояние результата.
- Чекбокс «Пропускать паузы» расположен перед следованием, по умолчанию выключен. [PlaybackPauseIndex](../../Sources/LocalScribe/PlaybackPauseIndex.swift) вне MainActor строит индекс промежутков ≥ 1000 мс между целыми репликами-абзацами (`Segment.endMs` → следующий `startMs`), объединяя перекрывающиеся интервалы речи. Тишину до первой реплики пропускать при воспроизведении, даже если она короче секунды; после последней реплики не пропускать. Word timings не используются.
- Автопереход действует только при воспроизведении, сохраняет скорость и использует обычную точную перемотку AVPlayer. Перемотка на паузе остаётся точной; возобновление внутри пропускаемой паузы сразу переходит к следующей реплике. Расшифровка подключается независимо от выбранной вкладки, её замена пересоздаёт индекс, смена источника/закрытие карточки сбрасывает его и отменяет устаревшую публикацию.

- Обезличивание в Core: [AnonymizationContractsTests](../../Tests/LocalScribeTests/AnonymizationContractsTests.swift), [AnonymizationRepositoryTests](../../Tests/LocalScribeTests/AnonymizationRepositoryTests.swift), [AnonymizationCoordinatorTests](../../Tests/LocalScribeTests/AnonymizationCoordinatorTests.swift), [AnonymizationEditingTests](../../Tests/LocalScribeTests/AnonymizationEditingTests.swift), [AnonymizationSettingsTests](../../Tests/LocalScribeTests/AnonymizationSettingsTests.swift), [ModelPackageTests](../../Tests/LocalScribeTests/ModelPackageTests.swift), [TextImportTests](../../Tests/LocalScribeTests/TextImportTests.swift).
- Обезличивание в UI/worker проверяют [AnonymizationModelSettingsTests](../../Tests/LocalScribeUITests/AnonymizationModelSettingsTests.swift), [AnonymizationWorkspaceTests](../../Tests/LocalScribeUITests/AnonymizationWorkspaceTests.swift), [AnonymizationImportTests](../../Tests/LocalScribeUITests/AnonymizationImportTests.swift), [AnonymizationQueueTests](../../Tests/LocalScribeUITests/AnonymizationQueueTests.swift) (фикстура worker.py выполняет все три вида команд), [AnonymizationCardEditorTests](../../Tests/LocalScribeUITests/AnonymizationCardEditorTests.swift), [AnonymizationDeletionTests](../../Tests/LocalScribeUITests/AnonymizationDeletionTests.swift), [AnonymizationDownloadTests](../../Tests/LocalScribeUITests/AnonymizationDownloadTests.swift), [AnonymizationSupervisorTests](../../Tests/LocalScribeUITests/AnonymizationSupervisorTests.swift).
- Worker-обезличивание: [AnonymizationEngineTests](../../Tests/LocalScribeDiarizationTests/AnonymizationEngineTests.swift) (фейковый recognizer) и [AnonymizationRoutingTests](../../Tests/LocalScribeDiarizationTests/AnonymizationRoutingTests.swift) (реальный бинарник). Версионный рубеж пайплайна для всех стадий и двойной замок трассировки схем — [PipelineVersionGateTests](../../Tests/LocalScribeDiarizationTests/PipelineVersionGateTests.swift) и DiagramEngineTests.
- Панели/диалоги в тестах только через швы (`chooseImportFiles`, `resolveAmbiguousEncoding`, `resolveDuplicateImport`, `chooseDownloadURL`): настоящий NSAlert в тестовом процессе вешает прогон.
- [AnonymizationRestorationTests](../../Tests/LocalScribeTests/AnonymizationRestorationTests.swift) проверяет точные совпадения и сохранность транзакции. [AnonymizationRestorationWorkspaceTests](../../Tests/LocalScribeUITests/AnonymizationRestorationWorkspaceTests.swift) покрывает импорт, вставку, подсветку, повтор, экспорт и удаление.
- Переходы между предупреждениями и текстом проверяет [AnonymizationCardEditorTests](../../Tests/LocalScribeUITests/AnonymizationCardEditorTests.swift), двустороннюю прокрутку и выключение синхронизации — [AnonymizationScrollSyncTests](../../Tests/LocalScribeUITests/AnonymizationScrollSyncTests.swift).
- Реальный VLM схем включается через `LOCALSCRIBE_DIAGRAM_FIXTURE_MODELS` + `LOCALSCRIBE_DIAGRAM_FIXTURE_IMAGES` (см. [DiagramRecognition](../../docs/DiagramRecognition.md)); без них DiagramVLMFixtureTests пропускается.
- Регрессии схем без весов: [DiagramEngineTests](../../Tests/LocalScribeDiarizationTests/DiagramEngineTests.swift) (фейковый recognizer), [DiagramRoutingTests](../../Tests/LocalScribeDiarizationTests/DiagramRoutingTests.swift) (реальный бинарник), [DiagramRepositoryTests](../../Tests/LocalScribeTests/DiagramRepositoryTests.swift)/[DiagramCoordinatorTests](../../Tests/LocalScribeTests/DiagramCoordinatorTests.swift)/[DiagramExportTests](../../Tests/LocalScribeTests/DiagramExportTests.swift), [DiagramWorkspaceTests](../../Tests/LocalScribeUITests/DiagramWorkspaceTests.swift) (смешанная очередь, одинаковые UUID в двух архивах, отмена/удаление против completed, паузы).
- Общий sidebar и черновик настроек проверяются в [ContentLayoutTests](../../Tests/LocalScribeUITests/ContentLayoutTests.swift), включая персистентность темы приложения.
- Совместимость, выбор профилей и URL загрузки покрывают [ModelHardwareTests](../../Tests/LocalScribeTests/ModelHardwareTests.swift), [ModelCompatibilityTests](../../Tests/LocalScribeUITests/ModelCompatibilityTests.swift) и [DownloadServiceTests](../../Tests/LocalScribeUITests/DownloadServiceTests.swift).
- [DiagramPlantUMLSamplesTests](../../Tests/LocalScribeTests/DiagramExportTests.swift) пишет образцы для локальной проверки при заданном `LOCALSCRIBE_PUML_OUT`.
- Запуск с подменой разрешений и устройств проверяет [RecordingStartTests](../../Tests/LocalScribeUITests/RecordingStartTests.swift). Маршрутизацию, отбрасывание поздних пакетов и общую шкалу покрывают [MicrophoneRoutingTests](../../Tests/LocalScribeUITests/MicrophoneRoutingTests.swift), [CaptureIngressTests](../../Tests/LocalScribeUITests/CaptureIngressTests.swift) и [TimedCaptureWriterTests](../../Tests/LocalScribeUITests/TimedCaptureWriterTests.swift).
- «В эфире» проверяют [BackgroundRecognitionTests](../../Tests/LocalScribeUITests/BackgroundRecognitionTests.swift), [ContentLayoutTests](../../Tests/LocalScribeUITests/ContentLayoutTests.swift), [ProcessingQueueTests](../../Tests/LocalScribeUITests/ProcessingQueueTests.swift) и [RecordingStartTests](../../Tests/LocalScribeUITests/RecordingStartTests.swift). Контракты GigaAM без runtime и весов проверяют [GigaAMASREngineTests](../../Tests/LocalScribeDiarizationTests/GigaAMASREngineTests.swift).
- Плеер, переходы между репликами, шаги перемотки и пропуск пауз (начальная тишина, порог внутренних пауз, перекрытия, скорость, включение на ходу, смена расшифровки/источника и повторное открытие карточки) проверяют [RecordingPlaybackTests](../../Tests/LocalScribeUITests/RecordingPlaybackTests.swift), размещение и действие чекбокса — [ContentLayoutTests](../../Tests/LocalScribeUITests/ContentLayoutTests.swift), подсветку и выделение текста — [ResultTextTests](../../Tests/LocalScribeUITests/ResultTextTests.swift). Синтетический WAV создаётся локально. Проверка импортируемых форматов требует `Assets/tools/ffmpeg` и образцы MP3, Ogg и Opus в `Assets/format-fixtures`.
- Происхождение ASR-модели после копирования расшифровки, при новом pending run и повреждённых ссылках проверяет [ResultReadingTests](../../Tests/LocalScribeTests/ResultReadingTests.swift); строку модели и диапазоны таймкодов — [ExportTests](../../Tests/LocalScribeTests/ExportTests.swift).
- Каталоги и перевод сообщений проверяет [LocalizationTests](../../Tests/LocalScribeTests/LocalizationTests.swift).
- Клавиатурные команды рабочего окна проверяются в [WorkspaceKeyboardTests](../../Tests/LocalScribeUITests/WorkspaceKeyboardTests.swift).
- Навигация стрелками по трём разделам — в [SidebarArrowNavigationTests](../../Tests/LocalScribeUITests/SidebarArrowNavigationTests.swift) через реальные key-события и hosted-окно (для схем и текстов выделение читается по заголовку открытой карточки в AX-дереве).
- Два модельных теста диаризации требуют `LOCALSCRIBE_DIARIZATION_FIXTURE_MODELS` и `LOCALSCRIBE_DIARIZATION_FIXTURE_WAV` ([DiarizationTailFix](../../docs/DiarizationTailFix.md)). Переменные для реальных Whisper, Qwen3 и VibeVoice перечислены в [ASRModels](../../docs/ASRModels.md), технические Whisper-пробы — в [ASRMatrix](../../docs/ASRMatrix.md). Обычные регрессии работают без весов с fake predictors/transcribe.
- Для групп/выделения/поиска использовать [RecordingGroupsTests](../../Tests/LocalScribeTests/RecordingGroupsTests.swift), [RecordingGroupIntegrationTests](../../Tests/LocalScribeUITests/RecordingGroupIntegrationTests.swift), [SidebarSelectionTests](../../Tests/LocalScribeUITests/SidebarSelectionTests.swift), [RecordingTitleSearchTests](../../Tests/LocalScribeTests/RecordingTitleSearchTests.swift) и [RecordingSearchIntegrationTests](../../Tests/LocalScribeUITests/RecordingSearchIntegrationTests.swift).
- Они покрывают временные архивы, частичные отказы, нативный ввод/меню, независимый OSA-oracle, поздние ответы/отмену и отсутствие I/O при поиске.
- Два нативных DnD-теста пропускаются без `LOCALSCRIBE_DND_APP`, указывающей на собранную и зарегистрированную в Launch Services `.app` ([RecordingGroups](../../docs/RecordingGroups.md)).
- [RecordingSearchPerformanceTests](../../Tests/LocalScribeUITests/RecordingSearchPerformanceTests.swift) включается через `LOCALSCRIBE_SEARCH_BENCHMARK=1`. Замеры из [отчёта](../../docs/RecordingTitleSearch.md) не заменяют ручную приёмку готовой `.app`, VoiceOver/IME или Instruments.
- При изменении аудиоимпорта запускать [AACImportTests](../../Tests/LocalScribeTests/AACImportTests.swift): пакетная длительность ADTS, некорректные/переполняющие значения, граница трёх часов, M4A и отмена.
- Интеграционный тест создаёт AAC через системный `afconvert`, использует `Assets/tools` и проверяет probe → импорт → prepare с сохранением SHA оригинала; без tools он пропускается, поэтому число пропусков может вырасти.
- Файлы/модели создаются во временных UUID-каталогах и удаляются через `defer`; использовать `RecordingRepository(root:)`, `localSource` и замыкание `fetch`.
- Для AppModel — `startServices: false`, отдельные UserDefaults и `workerExecutable` с тестовым процессом. Образцы — [RunResumptionTests](../../Tests/LocalScribeTests/RunResumptionTests.swift), [ProcessingQueueTests](../../Tests/LocalScribeUITests/ProcessingQueueTests.swift).
- Автоматическая оценка сессии 6 завершена, полная приёмка не пройдена: лимит summary15 на исходной встрече, перевод русских реплик и ошибки/дубли итогов остаются блокерами. Финальный эталон 511 слов уже раскрыт; после настройки нужен новый независимый набор.
- Источник состояния — [ASRExperimentStatus](../../docs/ASRExperimentStatus.md); тексты и эталоны держать в игнорируемом `TestResults`, числовые результаты не выдавать за полную WER/DER-приёмку.
- При изменении хранения проверять сохранность внешних оригиналов/экспортов, старого active run и повреждённых элементов архива.
- При изменении моделей — отмену, SHA, прогресс, совместимость профилей и legacy-папок; при продолжении — неизменность pending/active run и checkpoints при отсутствующих/повреждённых моделях или смене ревизии.
- Перед изменением обработки читать [Architecture](../../docs/Architecture.md); перед модельным UI/установкой — [ModelManagement](../../docs/ModelManagement.md).
- Интеграционные проверки требуют собранных helper/tools, а для анализа — локальных весов и технического аудио.
- Настоящий путь worker получать командой выше: жёсткий `.build/out/Products/Release` из старых скриптов может отличаться.
- XCTest не подтверждает sandbox/TCC, работу микрофона или качество моделей. Для таких изменений читать [Acceptance](../../docs/Acceptance.md) и [MacAcceptance](../../docs/MacAcceptance.md); синтетическая речь не заменяет WER/DER и трёхчасовую приёмку на реальных встречах.
