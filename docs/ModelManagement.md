# Управление моделями: проверка 17 октября 2026

Добавлены варианты Whisper small / medium / large-v3-turbo / large-v3 и Qwen3.5 4B / 9B / 27B (4-bit). Ревизии и файлы исходных четырёх профилей сохранены; новые варианты закреплены по ревизии, размеру и SHA-256. Совместимый токенизатор выбирается вместе с Whisper. Модели хранятся в отдельных папках; выбор и даты установки — в `models/selection.json`.

Подтверждено:

- `swift test -c release -j 4 --force-resolved-versions`: 21 тест, 0 ошибок. Восемь новых тестов покрывают общий прогресс и повторное использование проверенных файлов, сетевые сообщения в байтах, отмену, сохранение выбора после перезапуска, удаление и выбор оставшейся модели, миграцию старых папок, повреждение модели, сохранность архива, привязку профилей к заданиям, пересоздание итогов с прежней расшифровкой и предупреждения по RAM/Metal.
- Release-сборка приложения, worker и XPC-сервиса; `codesign --verify --deep --strict` успешен.
- В отдельной диагностической копии с bundle ID `local.localscribe.mac.modelscheck` выполнен `--self-check --self-check-download`. Подписанная цепочка GUI → worker → FFmpeg успешна. XPC скачал настоящий файл токенизатора: 2072 байта; полученный прогресс — 2072 байта; SHA-256 совпала. Пользовательский архив для этой проверки не использовался.
- Отдельный сетевой тест нового `ModelFileDownload` подтвердил callback о 34648 байтах до возврата скачанного файла. Используется явный `URLSessionDownloadTask`: асинхронный `URLSession.download(from:delegate:)` в проверенной среде не вызывал download-progress callbacks.
- В интерфейсе диагностической копии проверены список вариантов итогов, отображение характеристик Apple M1 / 8 CPU / 16 ГБ RAM, предупреждение для Qwen 27B и диалог перед загрузкой. Загрузка тяжёлых весов в этой проверке отменена до начала.

Ограничения: новые веса целиком не скачивались; скорость, качество распознавания/итогов и фактический пик RAM для каждого нового варианта не измерялись. Требования RAM и рабочего объёма GPU в каталоге — консервативные ориентиры. Прежние предупреждения компилятора о Sendable в `MicrophoneRecorder` не относятся к этому изменению.
