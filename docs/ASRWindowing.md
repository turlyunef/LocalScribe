# Окна ASR и числовая диагностика

20.10.2026, `asr7`: выборочно отменена оптимизация ASR из `ed9a818`.
Восстановлен алгоритм выбора первой паузы из `asr5`; повторы внутренних
пропусков и хвоста из `asr6` удалены. Один последовательный worker, выбранные
модели и числовая диагностика сохраняются. Изменения итогов, интерфейса,
очереди и записи микрофона в откат не входят.

## Выбор окна

Окно заканчивается на первой паузе около 600 мс после первых двух секунд.
Граница располагается внутри паузы по прежнему алгоритму `asr5`; если паузы
нет, используется весь доступный интервал до 28 секунд. Короткие фрагменты
и хвосты не отбрасываются. Эти правила применяет общий `SpeechRecognizer`
при обработке завершённой записи и фоновых CAF.

Порог энергии используется только для выбора границы. Он не доказывает
наличие или отсутствие речи. Вход Whisper сохраняет реальный контекст
по секунде с обеих сторон и не превышает 30 секунд. Ни паузы, ни участки
оригинала не удаляются; принадлежность слов определяется серединой их
интервала в исходной шкале времени. Определение языка, фильтры результата,
word timings и повтор восстановления начала из `ASRPrefixFix.md` сохранены.

В `asr6` (19.10.2026) выбиралась последняя завершённая пауза от 14-й секунды,
а внутренние пропуски и хвост получали локальный повтор с контекстом по 250 мс.
Объединение реплик меняло контекст декодера; ранний вариант терял английскую
реплику на техническом RU → EN → RU примере. Локальный повтор помог на этом
примере, но качество на реальных встречах не было подтверждено. Обе эти
эвристики отменены для повторной проверки качества на той же старой записи.
Откат сам по себе не доказывает улучшения.

Новый `RunInfo.pipelineVersion` (`asr7`, остальные компоненты версии сохранены)
меняет fingerprint ASR и итогов: SummaryEngine
хэширует полную транскрипцию, включающую этот fingerprint. Поэтому изменение
не требует нового prompt, но не смешивается с прежними контрольными точками.
Готовые старые результаты остаются читаемыми; повторная обработка создаёт
новое задание по существующим правилам репозитория. Для сравнения следует
выбрать «Обработать заново» с той же моделью. «Продолжить» сохраняет старое
задание и отклоняет несовместимую версию, не изменяя его контрольные точки.

## `runs/<run>/metrics-asr.json`

Отдельный ограниченный по размеру JSON сохраняется атомарно через `Disk.write`.
Это диагностика одной попытки запуска этапа, не контрольная точка результатов.
Ошибки записи диагностики не отменяют успешное распознавание. Обычные
`metrics-transcribing.json` с временем этапа и RSS остаются без изменений.

| Поле | Смысл |
| --- | --- |
| `status` | `running`, `completed`, `failed`, `cancelled`; после принудительного EOF/завершения может остаться `running` |
| `elapsedSeconds` | Время текущей попытки по монотонным часам, включая загрузку; для live также ожидание аудио и охлаждения |
| `modelLoadSeconds` | Загрузка и prewarm Whisper, включая неудачную попытку |
| `plannedWindows` | Число, сумма, минимум, максимум, среднее и гистограмма основных интервалов без контекста |
| `silentWindows` | Интервалы, пропущенные существующей проверкой почти цифровой тишины |
| `checkpointHits`, `checkpointAudioMs` | Повторно использованные части и их длительность; не входят в новые окна и вызовы модели |
| `primary` | Вызовы основного распознавания |
| `prefixRecovery` | Отдельные вызовы восстановления пропущенного начала; `inputs.count` — точное число запущенных повторов |
| `gapRecovery` | Поле прежней диагностики сохранено; в `asr7` вызовов нет |
| `unrecoveredPrefixes` | Проверки, после которых начало осталось нераспознанным и отправлено предупреждение |
| `unrecoveredGaps` | Поле прежней диагностики сохранено; в `asr7` равно нулю |

`windowPolicy = first-pause-prefix-recovery` отмечает восстановленный подход.
Для групп вызовов `inputs` измеряет фактический вход модели с контекстом
(до внутреннего дополнения нулями). Гистограмма содержит шесть корзин:
`[0,5)`, `[5,10)`, `[10,20)`, `[20,28)`, `[28,30]`, `>30` секунд.
`completedCalls` и `failedCalls` разделяют завершённые и оборванные вызовы;
во время вызова их сумма может быть меньше `inputs.count`.

`wallSeconds` — полное время вызовов, включая неудачные. `encoderSeconds`
и `encoderRuns` — время и число проходов encoder из WhisperKit.
`decoderInferenceSeconds` — модельные предсказания decoder, включая определение
языка; это не полное время генерации с обработкой токенов. Отдельно сохраняются
`decoderTokenLoops`, `logMelSeconds` и `wordAlignmentSeconds`.

`sdkDecodingLoopSeconds` в WhisperKit включает encoder и выравнивание:
нельзя выдавать его за чистое время decoder или складывать с ними.
`sdkReportedFallbacks` сохраняет необработанное поле SDK. В закреплённом
WhisperKit 1.1.1 оно присваивается из индекса попытки при отказе и не является
точным накопительным числом температурных повторов. Повторы восстановления
начала считаются независимо и точно. SDK-времена доступны только для успешно
вернувшихся результатов; при ошибке сохраняются счётчик и wall time.

При повторном запуске файл сбрасывается, готовые части учитываются через
`checkpointHits`. Сравнивать скорость следует при одинаковых кэше, модели,
аудио и температурном состоянии Mac, отдельно от времени загрузки.
Диагностика не содержит речи, токенов, путей, идентификаторов реплик или
текстов ошибок SDK. Во время inference не используются callbacks с текстом.

## Проверки

`ASRWindowTests` проверяет выбор первой паузы, непрерывное покрытие,
тишину, тихий сигнал и короткие хвосты. `SpeechRecognizerTests` проверяет
фактическое разбиение входа с паузой, контекст, исходные таймкоды,
восстановление начала, отсутствие локальных повторов внутренних пропусков
и хвоста, границы live, ошибки и отсутствие текста в диагностике.
`RunResumptionTests` проверяет отказ продолжения `asr6` без изменения
manifest, run и контрольной точки, включая сохранение прежнего active run.

`ASRModelFixtureTests/testMixedLanguageFixtureWithRestoredWindowPolicy` —
опциональная проверка обоих языков на настоящей модели с текущей стратегией.
Нужны `LOCALSCRIBE_ASR_FIXTURE_MODELS` (локальные `asr` и `tokenizer`) и
`LOCALSCRIBE_ASR_FIXTURE_WAV` (техническое RU/EN-аудио, mono/16 кГц).
`LOCALSCRIBE_ASR_PROBE_OUTPUT` задаёт папку для числовых результатов.
Процесс теста следует запускать с запретом сети, SDK stderr отбрасывать.
Без переменных тест явно пропускается. Наличие обоих языков и допустимых
таймкодов не доказывает отсутствие пропусков отдельных слов: для оценки
качества нужны реальные записи с ручным эталоном и WER.

Проверено 20.10.2026: отдельный временный SwiftPM-пакет с точными копиями
исходников Core, `SpeechRecognizer`, `ASRMetrics`, их тестов и локального
WhisperKit 1.1.1 из закреплённого checkout прошёл release-прогон через
`--build-system native -c release -j 4`: 145 XCTest, 0 ошибок, 1 модельный
пропуск. Совпадение копий исходников проверено по SHA-256. Пакет исключал
MLX, UI, Pipeline и диаризацию; это проверка ядра и ASR, не всего приложения.
Штатный `swift test -c release -j 4 --force-resolved-versions` остановился
при компиляции Metal в MLX: Metal Toolchain отсутствует. Полная сборка и
качество на реальной записи этим прогоном не подтверждены; `.app` не обновлялась.

## Исторический результат технического сравнения `asr6`, 19.10.2026

Ниже — замеры до отката; они не описывают текущий `asr7`.

На локальном Whisper large-v3 и `Assets/probe/mixed.wav` (синтетическое
RU → EN → RU аудио, 22,244 с) финальный вариант прошёл проверку обоих языков,
начала/конца, допустимых таймкодов и неизменности SHA аудио. Исходная стратегия
и новая запускались последовательно с одинаковыми настройками декодирования
и восстановления; основной измеряемый показатель исключает загрузку модели.

| Метрика | Первая пауза | Поздняя пауза с восстановлением |
| --- | ---: | ---: |
| Вызовы Whisper | 4 | 2 (основной + один локальный повтор) |
| Проходы encoder | 5 | 3 |
| Время вызовов Whisper | 38,890 с | 31,451 с |
| Время encoder | 11,282 с | 5,314 с |
| Предсказания decoder | 27,073 с | 25,662 с |
| Загрузка/prewarm модели | 0,789 с | 0,736 с |

На этом прогоне время вызовов уменьшилось на 19,1%. Русских букв в обоих
результатах 164, латинских — 83 и 82; это контроль сохранения языков, а не WER
и не доказательство идентичного текста. Результаты находятся в исключённой
из Git папке `TestResults/asr-windowing-2026-10-19-context250/`.
Ранний вариант без восстановления терял всю английскую реплику и не принят.
Для восстановления контекст по 1 с тоже не помог на этом примере; с 250 мс
проверка прошла. Эти числа относятся к одному техническому примеру и тёплым
модельным кэшам, не к общему ускорению и качеству на реальных встречах.

`swift test -c release -j 4 --force-resolved-versions` прошёл: 272 XCTest
(134 Core, 89 UI/service, 49 worker/диаризации), 0 ошибок, 3 модельных пропуска.
Опциональный ASR-тест отдельно выполнен с локальными весами и запретом сети.
Использованы существующие Metal-артефакты; чистая сборка Metal этим не проверена.

`python3 scripts/probe_live_capture.py` прошёл на production worker: первая
контрольная точка появилась до завершения записи, EOF завершил worker,
возобновление сохранило SHA первой части и довело покрытие до 40 125 мс.
Метрики новой попытки: `completed`, один checkpoint на 30 000 мс, одно новое
окно тихого хвоста и ноль новых вызовов Whisper. Probe использует изолированную
копию закреплённого каталога, локальные модели и отбрасывает SDK stderr.
