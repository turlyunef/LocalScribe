# LocalScribe 0.1.1 — остановка записи сразу после старта

Исправлено 17 октября 2026 года. Установленная копия: `/Applications/LocalScribe.app`, version 0.1.1 / build 2.

Причина: обработчик любого `AVAudioEngineConfigurationChange` безусловно останавливал запись и ошибочно сообщал о смене микрофона. На этом Mac при обычном старте приходит одно такое уведомление с прежним входом и работающим движком. Уведомление может относиться и к выходному устройству; Apple также описывает остановку/разинициализацию движка при изменениях I/O. [Документация Apple](https://developer.apple.com/documentation/foundation/nsnotification/name-swift.struct/avaudioengineconfigurationchange).

Теперь проверяются фактический Core Audio device ID, sample rate, число каналов и PCM-формат. При прежнем входе работающий движок продолжает запись; остановившийся движок перезапускается. Настоящая смена входа/формата или потеря микрофона останавливает запись. Перезапуски ограничены, возможный короткий пропуск явно отмечается предупреждением. Проверка и восстановление выполняются на главной очереди, после выхода из внутреннего callback AVAudioEngine.

Пустой старт больше не получает сообщение «Фрагменты сохранены». Попытка продолжить старую запись без законченных CAF сообщает, что нужно начать новую запись. Архивы и модели не удалялись.

## Фактические проверки на M1 / macOS 27.0.1

| Проверка | Результат |
|---|---|
| Обычный настоящий встроенный микрофон | 12,0 s, 576 000 сэмплов / 48 kHz, два законченных CAF; одно стартовое уведомление, 0 перезапусков, самопроизвольной остановки нет |
| Настоящий микрофон + искусственное служебное уведомление + остановка движка | 11,9 s, 571 200 сэмплов / 48 kHz, два CAF; 3 уведомления, 1 успешный перезапуск, запись продолжилась |
| Сборка оригинала | Число сэмплов после потоковой сборки равно записанному в обоих тестах |
| Регрессия | 13 XCTest-тестов без ошибок; отдельно проверены прежний вход при running/stopped, смена device ID/rate/channels/flags и отсутствие входа |
| Пакет | Release arm64, version 0.1.1, strict codesign; установленная копия проверена после замены |

Тестовый звук после каждого прогона удалён автоматически. В отчётах остались только числовые метаданные. Модели не запускались, в пользовательском архиве тестовые записи не создавались. Прежнее приложение сохранено в `TestResults/LocalScribe-before-microphone-fix.app` для отката.

Полноценные проверки смены физических устройств, сна, принудительного завершения и трёхчасовой микрофонной записи остаются в общей матрице приёмки. Установленная macOS 26 по-прежнему отдельно не проверена. Из-за локальной ad-hoc подписи macOS может заново запросить микрофон после обновления; системную защиту для этого отключать не нужно.
