# Этап 0: журнал технической проверки

Дата начала: 16.10.2026, Asia/Tomsk. Это журнал фактов, а не сертификат приёмки.

Окружение: MacBookAir10,1, Apple M1, 16 GB, Xcode 27.0 (27A266a), Swift 6.4. Система сообщает macOS 27.0.1 (26A434), Darwin 27.0.0. Deployment target приложения — macOS 26. Проверка на установленной macOS 26 остаётся обязательной.

## Кандидаты и решения

- Argmax OSS 1.1.1, commit `1bbc57cb7fe6410248a685b1c5a3c6d56adc2ed4`: открытые WhisperKit и SpeakerKit, без Pro. В исходниках подтверждены локальные папки и глобальный Pyannote-проход; numberOfSpeakers по умолчанию не задан.
- MLX Swift LM 2.30.6 отклонён: в этом релизе отсутствует Qwen3.5. Выбрана 2.31.3, commit `25b00d4e22e61ec9c41efda47990cd2084ec87ff`: `qwen3_5`, `qwen3_5_text`, текстовый `Qwen35Model` без visual tower. Это замена версии SDK, не модели.
- Транзитивные версии зафиксированы в `Package.resolved`. MLXFoundationModels/MLXVLM не подключены к worker.
- FFmpeg 8.0.1 собирается из официального архива: только локальные протоколы file/pipe, встроенные аудиодекодеры, без autodetect, GPL и nonfree. Конфигурация, исходники и SHA-256 сохраняются сборкой.
- Модели закреплены в `Resources/models.lock.json`: immutable Hugging Face commits, размеры, SHA-256 всех используемых артефактов; SHA небольших Git-файлов рассчитана по полученным байтам, LFS SHA получена через HF blobs API.
- Whisper large-v3: `0f63a7800b00dd0226abd051b906c246e1907482`, 3 090 319 899 байт. Токенизатор отдельно из openai/whisper-large-v3, также закреплён.
- SpeakerKit: `556fc52a13327837688f02289457cded017802e9`, выбранные W8A16 segmenter/embedder и W32A32 PLDA — 11 244 008 байт. Не весь многовариантный репозиторий.
- Qwen3.5-9B-4bit: `8b2b98c00a6b4d291155e4890773ca8f769aee53`, 5 977 071 733 байт. SDK фильтрует visual weights; сами shard-файлы конвертации остаются исходными и проходят SHA-256.

## Обнаруженные ограничения окружения

Первая Release-сборка дошла до Metal и завершилась ошибкой: Xcode не содержал дополнительный Metal Toolchain. Компонент установлен официальной командой `xcodebuild -downloadComponent MetalToolchain`; последующие Release-сборки прошли. Детали ниже.

WhisperKit при неисправном локальном токенизаторе способен перейти к сетевой загрузке. Worker дополнительно применяет системный профиль, запрещающий сеть, и прекращает запуск, если ограничение не установлено. Это проверяется именно с упакованным приложением. SDK stderr не сохраняется приложением: даже неявный вывод текста библиотеки не должен попадать в логи.

## Проверки, остающиеся после технических прогонов

- Совместный пик памяти UI + worker; скорость, swap, thermal state.
- 10–20 минут RU/EN, полноценные 3 часа речи, возвращение спикера через час.
- Сравнение full large-v3 и multilingual Turbo на одинаковом размеченном наборе.
- Холодный автономный запуск после перезагрузки.
- Микрофон/TCC и GUI, чистый Mac без Homebrew, установленная macOS 26.

Качество WER/DER и смысловая точность не могут быть объявлены проверенными без эталонных записей. Синтетическая речь допустима только для проверки API, не для этих метрик. Приложение не содержит демонстрационных расшифровок.

## Фактически выполненные проверки 16–17 октября

1. Установлен официальный Metal Toolchain 27A266a, `metal` 32023.921. Обе Release-программы собраны; `codesign --verify --deep --strict` проходит для .app со всеми вложенными компонентами. Добавленный XPC-загрузчик также собирается и подписывается.
2. Все четыре комплекта моделей скачаны, каждый файл проверен по SHA-256 до перевода `.partial` в готовый каталог. Всего 9 083 018 913 байт по манифесту. Веса остаются отдельно от .app.
3. Реальный короткий ASR + SpeakerKit: синтетический RU → EN → RU, 22,2435625 s. После обнаружения пропуска EN в общем окне добавлено разбиение по паузам. Исправленный прогон: ASR 77,01 s, RSS 3 809 837 056 байт; диаризация 12,40 s, RSS 148 897 792 байт. В тексте присутствуют оба языка, голоса RU/EN разделены; первое английское слово имеет неточный timestamp и неизвестного участника — это зафиксированный проблемный пример, не скрытая ошибка.
4. SpeakerKit OSS обработал 10 800 s синтетической речи глобально: 108,8908 s, RSS 2 421 866 496 байт, 2 голоса, 1460 интервалов. Аудио повторяет два TTS-голоса. Это измерение размера входа/памяти, не DER настоящей встречи и не тест возврата после часового отсутствия.
5. Настоящий Qwen3.5-9B-4bit загрузился через MLXLLM из локальной папки при системном запрете сети. Первые ответы отклонены из-за неверного типа overview и неподтверждённых имён/сроков. Добавлены формальная JSON-схема, информативная одна повторная попытка, извлечение каждого языка, консервативное обнуление неподтверждённых optional-полей без удаления поддержанного действия. Проверяется фактически токенизированный суффикс отключённого thinking и EOS; `llm-audit.json` хранит только счётчики и флаги. Результат финального технического контроля приведён ниже; приёмка на настоящих встречах не подменяется этим тестом.
6. Первая подписанная цепочка UI → worker завершилась кодом 70: macOS запрещает повторную инициализацию унаследованного App Sandbox. Ранее работавший developer probe не был доказательством работы .app. Исправлено: GUI без network.client, worker наследует этот запрет; download вынесен в отдельный XPC-процесс с сетью. Попытка shared bookmark между ad-hoc идентичностями не прошла; окончательный вариант передаёт только файловый дескриптор и вообще не даёт загрузчику доступ к архиву/папке моделей. Подписанная диагностика UI → worker → встроенный FFmpeg и XPC descriptor **прошла**. Реальная загрузка небольшого закреплённого tokenizer-файла через XPC также прошла SHA-256.
7. Встроенные декодеры проверены на WAV, AAC/ALAC M4A, FLAC (локальный синтетический исходник) и MP3, OGG Vorbis, OGG Opus, OPUS (публичный codec corpus FFmpeg). Все успешно прошли не только ffprobe/FFmpeg, но и настоящий этап `preparingAudio` с проверкой длительности/числа сэмплов. Отдельно через этот этап прошёл WAV ровно 3 часа без усечения. Эти файлы исключены из дистрибутива. Источники и SHA-256: `TestResults/external-codec-checks.json`.
8. Fault injection: закрытие stdin после started завершило worker кодом 72 за 0,0014 s, контрольные точки неизменны. Отсутствующая модель диаризации и LLM дали failed/code 1, хэши ASR, транскрипции и прежнего summary не изменились. Это не заменяет весь набор гонок/принудительного kill GUI.

RSS — resident size отдельного worker, а не общая unified memory. Значения нельзя складывать в обещание скорости: часть проб совпала со сборками; холодный/тёплый режим, swap delta, питание и thermal state для воспроизводимого бенчмарка пока не контролировались.

9. После полной подписанной цепочки обнаружен и устранён дефект упаковки MLX: CLI helper не находил Metal-библиотеку через GUI Bundle.main. `mlx.metallib` размещена рядом с worker и отдельно подписана; strict codesign и настоящая генерация Qwen из .app прошли.
10. В Mach-O FFmpeg обнаружен минимум macOS 27 от build host. Выполнена чистая пересборка с `-mmacosx-version-min=26.0` для C и linker. Проверены minos 26.0 всех пяти executable. Все девять codec/preparingAudio проверок повторно прошли с этой сборкой. Это не доказательство фактического запуска на macOS 26.
11. Двенадцать XCTest-тестов прошли без ошибок 17.10.2026 в 02:04:53 Asia/Tomsk. Цифровая тишина дала 0 сегментов/задач/решений. Синтетический разговор без поручений дал 0 задач/решений; полнота содержания проверяется отдельно.
12. Дополнительные проверки: повреждённый контейнер и WAV на 10 800,001 s отклонены настоящим worker без опубликованного WAV; исходные SHA не изменились. Стерео в противофазе дало предупреждение и сохранённый сигнал. SIGKILL отдельного тестового родителя остановил standalone worker за 0,0065 s; это не тест UI-гонок.

13. Окончательный модельный профиль `1.0.0-audio2-asr3-summary10` прошёл все этапы из подписанного sandbox на 22,244 s RU/EN/RU. Получены 4 сегмента, 2 голоса, итоги на русском, **2 задачи** (импорт файлов / микрофон) и **1 решение** (проверка релиза завтра). Повторы объединены с сохранением обеих ссылок. Имена и сроки задач отсутствуют, поскольку в источнике они не указаны. Ранее найденные пропуски EN и ложное удаление поручений при поздней проверке исправлены специализированными вердиктами по цитатам. Отдельный разговор без поручений дал 1 пункт содержания, 0 задач, 0 решений.
14. Последние измерения worker: ASR 44,0645 s / RSS 3 830 792 192 байт; диаризация 10,4724 s / 162 398 208 байт; LLM 245,7796 s / 3 049 259 008 байт. Максимальный вход Qwen 996 токенов + резерв ответа 2000, лимит 8192; thinking отключён через реальный template, ответы завершились EOS. Это технические числа с короткого синтетического аудио, не прогноз времени настоящих встреч. Весь конвейер занял около пяти минут без учёта установки/проверки весов.
15. Дополнительные исправления хранения/UI прошли повторную сборку: чужой UUID внутри manifest не может перезаписать соседнюю запись при recover, старый текст не остаётся под заголовком новой выбранной записи. Модельные адаптеры после сквозной проверки не менялись. GUI-проверка отображения остаётся ручной.
