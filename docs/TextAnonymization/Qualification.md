# Квалификация комплектов и пределов обезличивания

Процедура пункта 13 [плана реализации](ImplementationPlan.md): реальные локальные прогоны на целевых Mac подтверждают пригодность профилей для объявленных задач, полный проход в заявленной байтовой границе, работу без сети и доступную рабочую память. [Риск и его снятие](ImplementationPlan.md#risks), [назначения и готовность моделей](TextAnonymizationTechnicalDesign.md#назначения-и-готовность-моделей).

До квалификации действует консервативная оценка предела по бюджету памяти Mac ([AnonymizationInputLimit](../../Sources/LocalScribeCore/ModelTasks.swift)). Список моделей на вкладке «Обезличивание» пока пуст.

## Что уже зафиксировано в каталоге без замеров

Офлайн-часть пункта 13 выполнена честно: в каталоге отмечены только задачи, подтверждённые поставленным поведением, без приписывания неподтверждённой поддержки.

- Профили итогов несут `supportedTasks: ["SUMMARY"]`, профили схем — `["DIAGRAM_RECOGNITION"]`. Эти значения совпадают с множеством, которое [ModelTasks](../../Sources/LocalScribeCore/ModelTasks.swift) выводит из роли, поэтому выбор моделей и готовность не меняются; штамп делает каталог самодостаточным и задаёт точную форму записи для будущих результатов.
- `ANONYMIZATION` не присвоен ни одному профилю и не может появиться без квалификации: worker отвергает профиль без этой задачи безопасным отказом, UI не показывает таких кандидатов.
- `packageID` в каталоге не записывается: приложение вычисляет его из закреплённых файлов ([ModelPackage.identity](../../Sources/LocalScribeCore/ModelPackages.swift) — `pkg-<SHA-256>` от отсортированных строк `localPath:size:sha256`), поэтому профили с одинаковым набором файлов автоматически делят одну установку.
- `anonymizationInputLimitBytes` отсутствует: до замеров предел равен консервативному потолку пары «профиль и Mac» — 256 / 512 / 1024 КиБ при бюджете модели до 16 / 32 / от 32 ГБ. Значение из каталога не может поднять предел выше потолка данного Mac.

Штампы `SUMMARY` воспроизводятся генератором [lock_models.py](../../scripts/lock_models.py) (`VERIFIED_TASKS`); профили схем и прочие отдельно сверенные записи перегенерация сохраняет без изменений. Новые значения квалификации вносятся одновременно в каталог и в генератор, чтобы будущая перегенерация их не потеряла.

## Инструмент: `--probe-anonymization`

Техническая проба разработчика по образцу `--probe-diagram` ([Architecture](../Architecture.md): диагностика с текстом разрешена только явному техническому probe). Запуск из каталога пакета; путь к бинарнику даёт `swift build -c release --show-bin-path`.

```
LocalScribeWorker --probe-anonymization <корень моделей> <входной.json> [выходной.json]
```

- `<корень моделей>` — каталог `models`, содержащий `<ID профиля>/…` и каталог рядом (`models.lock.json` или `tools/models.lock.json`), та же граница, что у штатной команды worker.
- `<входной.json>` — артефакт попытки `AnonymizationAttemptInput` (`input.json`): закреплённые `fileId`, `attemptId`, исходник, имя импорта, формат, список типов, `profileID` и `packageID`. Проба сверяет пакет, совместимость с Mac и полные размеры/SHA всех файлов комплекта.
- Проба обходит шлюз задачи `ANONYMIZATION` в каталоге — она и есть инструмент квалификации до простановки задачи; все проверки целостности при этом сохраняются.
- Проба запускает настоящий конвейер (окна → распознавание → разрешение → подстановки → сборка) и пишет `result.json` рядом со входом или по третьему пути. Метрики печатаются одной JSON-строкой в protocol-stdout: `status`, `seconds`, `maxResidentBytes`, `windowCount`, `bodyCandidateCount`, `nameCandidateCount`, `bodyReplacementCount`, `nameReplacementCount`, `doubtfulCount`, `uninterpretedTypeCount`, `newSubstitutionCount`.
- Сетевой запрет worker (`CWorkerIsolation`) действует и на пробу: прогон по построению офлайновый. Для приёмки AC-11 сеть дополнительно отключается на уровне системы.
- Флаг `--trace-model-output` раскрывает исходные ошибки SDK, как у аудио- и схемных проб.

`packageID` для входа вычисляется по закреплённым файлам профиля (формула `ModelPackage.identity`):

```python
import hashlib, json
profile = next(m for m in json.load(open('Resources/models.lock.json'))['models'] if m['id'] == '<ID профиля>')
canonical = "\n".join(sorted(f"{f['localPath']}:{f['size']}:{f['sha256']}" for f in profile['files']))
print('pkg-' + hashlib.sha256(canonical.encode('utf-8')).hexdigest())
```

Контракт пробы без весов покрыт тестами [AnonymizationRoutingTests](../../Tests/LocalScribeDiarizationTests/AnonymizationRoutingTests.swift): отсутствие каталога и отсутствие установленного комплекта дают безопасный отказ с полным отчётом об ошибке.

## Шаги квалификации на целевом Mac

Предусловия: целевой Mac (Apple Silicon, macOS 26+), Release-сборка worker, комплект кандидата установлен и проверен приложением по SHA-256 (или файлы сверены с каталогом вручную), сеть отключена на уровне системы.

1. **Задачи, которые будут объявлены в каталоге.** Для обезличивания выполнить пробой три входа: русский TXT, английский Markdown и смешанный текст. Зафиксировать метрики пробы и качество замен по выборкам AC-12/13/41. Если для того же комплекта заявляются итоги или схемы, проверить их штатным маршрутом приложения или `--probe-diagram` без переустановки комплекта. [Критерии приёмки](../TextAnonymizationSpec.md#acceptance-criteria)
2. **Полный проход у границы.** Подготовить входы, длина текста которых в UTF-8 без BOM равна заявляемому пределу и на одно окно меньше; прогнать пробой. Проход подтверждён, когда каждый вход завершается полным `result.json` без обрыва генерации (`stopReason == stop`), без повторного отказа разбора после корректирующей попытки и без memory pressure.
3. **Память.** Сверить `maxResidentBytes` пробы с рабочим бюджетом Metal профиля и Mac ([ModelHardware](../../Sources/LocalScribeCore/ModelHardware.swift)): пик обязан укладываться в бюджет с системным резервом и не превышать `workingMemoryGB` профиля более чем на подтверждённый допуск; swap-давление не допускается.
4. **Офлайн.** Все прогоны шагов 1–3 выполняются при отключённой сети; фактом офлайна считается отсутствие обращений и штатный запрет сети worker.

Отказ кандидата: обрыв генерации, повторный отказ разбора, превышение бюджета памяти или любое сетевое обращение. Частичный успех понижает заявляемый предел и требует повтора шага 2 на новом пределе.

## Заполнение каталога по результатам

- `supportedTasks` содержит подтверждённые задачи профиля. После успешной проверки обезличивания добавляется `ANONYMIZATION`. Допустимые значения — `SUMMARY`, `DIAGRAM_RECOGNITION` и `ANONYMIZATION`.
- `anonymizationInputLimitBytes`: наибольший предел в байтах, на котором полный проход подтверждён (измерение — UTF-8 без BOM). Действует не выше консервативного потолка данного Mac; если подтверждённый предел выше потолка, сначала пересматривается оценка `AnonymizationInputLimit` по данным `ModelHardware`, затем значение каталога.
- `packageID` остаётся производным от закреплённых файлов; явное значение допускается только при сознательном алиасе профилей.
- Значения вносятся в [models.lock.json](../../Resources/models.lock.json) и одновременно в генератор (`VERIFIED_TASKS` и соседние данные [lock_models.py](../../scripts/lock_models.py)); перегенерация каталога с сети выполняется только по явному поручению ([команды](../../AGENTS.md#команды)).
- До коммита результатов измеренные пределы можно проверять подстановкой через `AppModel.inputLimits` (`AnonymizationInputLimit(overrides:)`) — тот же шов используют тесты.
