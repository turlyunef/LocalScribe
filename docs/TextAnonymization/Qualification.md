# Квалификация комплектов и пределов обезличивания

Процедура пункта 13 [плана реализации](ImplementationPlan.md): реальные локальные прогоны на целевых Mac подтверждают пригодность профилей для объявленных задач, полный проход в заявленной байтовой границе, работу без сети и доступную рабочую память. [Риск и его снятие](ImplementationPlan.md#risks), [назначения и готовность моделей](TextAnonymizationTechnicalDesign.md#назначения-и-готовность-моделей).

В [каталоге](../../Resources/models.lock.json) для обезличивания доступен Qwen3‑VL Instruct 8B 4-bit (`diagram-qwen3-vl-8b`). Предел 8 КиБ подтверждён на Apple M1 с 16 ГиБ RAM. Установленный комплект можно выбрать в настройках «Обезличивание».

## Кандидаты

Кандидаты зафиксированы в [технических примечаниях требований](../TextAnonymizationSpec.md#notes) и [Notes техдизайна](TextAnonymizationTechnicalDesign.md#notes). Кандидатом становится только профиль, уже закреплённый в каталоге: проба и приложение загружают веса исключительно по каталогу с проверкой размеров и SHA-256.

| Кандидат | Профиль каталога | Что подтверждено сейчас | Что требует квалификации |
| --- | --- | --- | --- |
| Qwen3‑VL Instruct 8B 4-bit | `diagram-qwen3-vl-8b` | распознавание схем и обезличивание | итоги |
| Qwen3‑VL Instruct 4B / 32B | `diagram-qwen3-vl-4b`, `diagram-qwen3-vl-32b` | распознавание схем | итоги и обезличивание |
| Qwen3.5 9B 4‑bit | `summary` | итоги записей ([журнал Stage0](../Stage0.md#кандидаты-и-решения)) | схемы и обезличивание |

Модель можно назначить каждой подтверждённой для неё задаче. Если модель поддерживает несколько задач, одна установка доступна на всех соответствующих вкладках.

## Назначения и пределы в каталоге

- У Qwen3‑VL 8B задачи `DIAGRAM_RECOGNITION` и `ANONYMIZATION`. Worker проверяет наличие `ANONYMIZATION` перед загрузкой весов. В настройках отображаются профили с этой задачей.
- `packageID` в каталоге не записывается: приложение вычисляет его из закреплённых файлов ([ModelPackage.identity](../../Sources/LocalScribeCore/ModelPackages.swift) — `pkg-<SHA-256>` от отсортированных строк `localPath:size:sha256`), поэтому профили с одинаковым набором файлов автоматически делят одну установку.
- `anonymizationInputLimitBytes` у Qwen3‑VL 8B равен 8192. [AnonymizationInputLimit](../../Sources/LocalScribeCore/ModelTasks.swift) ограничивает значение потолком памяти Mac.

Генератор [lock_models.py](../../scripts/lock_models.py) воспроизводит подтверждённые пределы и задачу `ANONYMIZATION` по ID профиля и точной ревизии комплекта (`VERIFIED_ANONYMIZATION`).

## Инструмент: `--probe-anonymization`

Техническая проба разработчика по образцу `--probe-diagram` ([Architecture](../Architecture.md): диагностика с текстом разрешена только явному техническому probe). Запуск из каталога пакета; путь к бинарнику даёт `swift build -c release --show-bin-path`.

```
LocalScribeWorker --probe-anonymization <корень моделей> <входной.json> [выходной.json]
```

- `<корень моделей>` — каталог `models`, содержащий `<ID профиля>/…` и каталог рядом (`models.lock.json` или `tools/models.lock.json`), та же граница, что у штатной команды worker.
- `<входной.json>` — артефакт попытки `AnonymizationAttemptInput` (`input.json`): закреплённые `fileId`, `attemptId`, исходник, имя импорта, формат, список типов, `profileID` и `packageID`. Проба сверяет пакет, совместимость с Mac и полные размеры/SHA всех файлов комплекта.
- Проба обходит шлюз задачи `ANONYMIZATION` в каталоге — она и есть инструмент квалификации до простановки задачи; все проверки целостности при этом сохраняются.
- Проба запускает штатный конвейер и пишет `result.json` рядом со входом или по третьему пути. Метрики печатаются одной JSON-строкой в protocol-stdout. `modelCallCount` учитывает фактические генерации, включая повторы и разбиение переполненного окна. `unverifiedWindowCount` считает окна с находками, которые не удалось привязать после повтора. Проба также сообщает время, пиковый RSS, число окон, кандидатов, замен и предупреждений.
- Сетевой запрет worker (`CWorkerIsolation`) действует и на пробу. Для приёмки AC-11 системный запрет можно применить ко всему дереву процессов прогона через `sandbox-exec -p '(version 1)(allow default)(deny network*)' …`.

`packageID` для входа вычисляется по закреплённым файлам профиля (формула `ModelPackage.identity`):

```python
import hashlib, json
profile = next(m for m in json.load(open('Resources/models.lock.json'))['models'] if m['id'] == '<ID профиля>')
canonical = "\n".join(sorted(f"{f['localPath']}:{f['size']}:{f['sha256']}" for f in profile['files']))
print('pkg-' + hashlib.sha256(canonical.encode('utf-8')).hexdigest())
```

Контракт пробы без весов покрыт тестами [AnonymizationRoutingTests](../../Tests/LocalScribeDiarizationTests/AnonymizationRoutingTests.swift): отсутствие каталога и отсутствие установленного комплекта дают безопасный отказ с полным отчётом об ошибке.

## Шаги квалификации на целевом Mac

Предусловия включают целевой Mac (Apple Silicon, macOS 26+), Release-сборку worker, локальный комплект кандидата с проверкой SHA-256 и системный запрет сети для прогона.

1. **Задачи, которые будут объявлены в каталоге.** Для обезличивания выполнить пробой три входа: русский TXT, английский Markdown и смешанный текст. Зафиксировать метрики пробы и качество замен по выборкам AC-12/13/41. Если для того же комплекта заявляются итоги или схемы, проверить их штатным маршрутом приложения или `--probe-diagram` без переустановки комплекта. [Критерии приёмки](../TextAnonymizationSpec.md#acceptance-criteria)
2. **Полный проход у границы.** Подготовить входы, длина текста которых в UTF-8 без BOM равна заявляемому пределу и на одно окно меньше; прогнать пробой. Проход подтверждён, когда каждый вход завершается полным `result.json` без обрыва генерации (`stopReason == stop`), без повторного отказа разбора после корректирующей попытки и без memory pressure.
3. **Память.** Сверить `maxResidentBytes` пробы с рабочим бюджетом Metal профиля и Mac ([ModelHardware](../../Sources/LocalScribeCore/ModelHardware.swift)): пик обязан укладываться в бюджет с системным резервом и не превышать `workingMemoryGB` профиля более чем на подтверждённый допуск; swap-давление не допускается.
4. **Офлайн.** Для прогонов шагов 1–3 использовать системный запрет сети. Worker дополнительно проверяет запрет соединений IPv4 и IPv6 до загрузки модели.

Отказ кандидата: обрыв генерации, повторный отказ разбора, превышение бюджета памяти или любое сетевое обращение. Частичный успех понижает заявляемый предел и требует повтора шага 2 на новом пределе.

## Заполнение каталога по результатам

- `supportedTasks` содержит подтверждённые задачи профиля. После успешной проверки обезличивания добавляется `ANONYMIZATION`. Допустимые значения — `SUMMARY`, `DIAGRAM_RECOGNITION` и `ANONYMIZATION`.
- `anonymizationInputLimitBytes`: наибольший предел в байтах, на котором полный проход подтверждён (измерение — UTF-8 без BOM). Действует не выше консервативного потолка данного Mac; если подтверждённый предел выше потолка, сначала пересматривается оценка `AnonymizationInputLimit` по данным `ModelHardware`, затем значение каталога.
- `packageID` остаётся производным от закреплённых файлов; явное значение допускается только при сознательном алиасе профилей.
- Значения вносятся в [models.lock.json](../../Resources/models.lock.json) и `VERIFIED_ANONYMIZATION` в [lock_models.py](../../scripts/lock_models.py). Перегенерация каталога с сети выполняется по явному поручению ([команды](../../AGENTS.md#команды)).
- До коммита результатов измеренные пределы можно проверять подстановкой через `AppModel.inputLimits` (`AnonymizationInputLimit(overrides:)`) — тот же шов используют тесты.
- Обновить таблицу статуса ниже и согласовать её с [журналом Stage0](../Stage0.md) и [ASRExperimentStatus](../ASRExperimentStatus.md) по стилю фактов.

Проверены единая подстановка для повторов, русские падежные формы, независимые подстановки для русских и английских имён, адрес `mailto:`, подстановка в имени файла и сохранение текста между заменами. Worker вычисляет позиции по дословным фрагментам исходника; фрагмент без кавычек-«ёлочек» закрепляется единственным сравнением без учёта кавычек. За исходные прогоны счётчик swapouts не вырос.

В версии 2.13 модель обрабатывала каждый тип в каждом окне отдельным вызовом. Многотипные ответы Qwen3‑VL 8B теряли целые типы. На резюме один вызов с шестью типами возвращал кандидатов только по исходным четырём, а в одном окне вернул пустой массив. Одиночный тип в том же окне находился полностью. Резюме примерно в 1,6 тыс. скаляров с шестью типами заняло 259 с и 18 вызовов. Более ранние синтетические входы в 8192 и 6692 байта прошли за 82 и 71 с при одном вызове на окно.

С версии 2.14 адреса email типового формата и однозначные телефоны проверяются локально для соответствующих встроенных типов. Неоднозначные случаи, имена, адреса и произвольные формулировки обрабатываются отдельными запросами модели. Окна передают соседний контекст. Проба различает корректный пустой ответ, непонятый тип и находки, которые не удалось сопоставить с исходником. Для сравнения версий на одинаковых размеченных входах сверять фактические диапазоны в `result.json`, пропуски, ложные замены, предупреждения, вызовы модели и время.

Штатная JSONL-команда `anonymization` завершилась событием `completed` на смешанном TXT с каталогом из собранной `.app`. Подпись сборки проверена отдельно.

Qwen3‑VL 4B пропускал падежную форму русского имени, а в пробе с окном 6000 скаляров дважды вернул ответ, который не разобрался как JSON. Qwen3.5 9B загрузился из обычной папки с проверенными весами, но в пробах пропускал часть целевых значений. Эти профили остаются кандидатами.
