# Очистка файлов, памяти и процессов — 18.10.2026

Проверены жизненные циклы импорта, микрофонной записи, worker, медиапроцессов, загрузки моделей, восстановления и выхода. Найденные проблемы исправлены в исходниках. Установленная `/Applications/LocalScribe.app` в этой задаче не заменялась.

## Найдено и исправлено

| Проблема | Исправление |
| --- | --- |
| После смерти родителя завершался worker, но оставался его медиапроцесс. Проверка с настоящим worker воспроизвела это. | `Media.execute` использует `posix_spawn`: дочерний процесс наследует группу worker, получает незаблокированные сигналы и стандартную обработку SIGTERM. Foundation `Process` создавал отдельную группу; одного исправления группы оказалось недостаточно из-за маски сигналов потока. Sandbox и запрет сети сохранены. |
| Ошибка импорта оставляла каталог с `.partial` без manifest. Ошибка создания повторного задания могла оставить неполный run. | Откат только нового, ещё не опубликованного каталога. Предыдущий manifest и active run сохраняются. |
| Сбой FFmpeg или сборки CAF оставлял `audio.partial.wav` / `original.caf.assembling.caf`. | Удаление промежуточного файла через `defer`, в том числе при ошибке проверки результата. Законченные фрагменты записи сохраняются. |
| Отмена/ошибка обработки оставляла рабочий WAV, а сбой после сохранения оригинала мог оставить дублирующий `capture`. | Очистка после завершения задания и при восстановлении приложения. Перед удалением проверяется SHA оригинала. Рабочий WAV при продолжении создаётся заново; JSON-контрольные точки остаются. |
| Отмена копирования модели сохраняла непроверенный недописанный файл. | Такой файл удаляется; ранее проверенные файлы `.partial` остаются для продолжения установки. |
| XPC-сервис удерживал соединение сильной ссылкой; скачанный файл имел временное имя до следующего запроса/освобождения. | Ссылка сервиса на соединение стала слабой. После открытия временное имя сразу удаляется; передача и чтение продолжаются через файловый дескриптор. Закрытие дескрипторов освобождает место. |
| Отмена XPC-запроса зависела от обратного вызова; ошибка записи команды worker обходила обработчик остановки. Читатели pipe могли пережить ошибку. | Отмена завершает continuation и инвалидирует соединение. Отправка команды включена в обработчик ошибок; оба читателя дожидаются завершения, каналы явно закрываются. История событий worker больше не накапливается в массиве. |
| Выход не ожидал установки моделей, импорта/ffprobe и сборки восстановленной записи. | Выход ожидает эти операции. При восстановлении записи исключены одновременные повторные сборки, удаление и начало новой записи. Наблюдатель сна и источник memory pressure освобождаются при завершении. |
| Удалённая запись оставалась в вспомогательном `index.json` до следующего сохранения. | Индекс обновляется сразу после удаления записи. |

Восстановление и проверка SHA выполняются вне главного актора. На это время изменения архива недоступны. Очистка пропускает неизвестные версии, повреждённые run и символьные ссылки каталогов run; при отсутствующем/изменённом оригинале дублирующее аудио сохраняется.

## Снимок локальных данных

Проверка без изменения пользовательского архива обнаружила два рабочих WAV отменённых заданий: **5 587 356 байт**. Новая сборка очистит их при запуске после проверки оригиналов. В проверенных временных каталогах GUI, XPC-сервиса и текущего пользователя файлов `localscribe-model-*` не найдено. В момент проверки процессов LocalScribe, FFmpeg и ffprobe не было.

Примерно 10,7 ГБ установленных моделей — постоянные данные. Оригиналы, успешные результаты, JSON-контрольные точки, закрытые фрагменты незавершённой записи и проверенные части установки модели не являются мусором. Технические `diagnostics`, `TestResults`, `Assets` и `.build` относятся к разработческим проверкам/сборке и не очищаются как пользовательский кэш.

## Проверки

- `swift test -c release -j 4 --force-resolved-versions`: **52 XCTest, 0 ошибок** — 44 теста Core и 8 тестов GUI/service. Покрыты откат импорта/run, очистка аудио, сохранение старых результатов и повреждённых записей, защита от символьных ссылок, отмена установки с последующим продолжением, отмена worker, освобождение XPC-объектов и удаление имени временного файла при работающем дескрипторе.
- Повторные успешные и неудачные запуски медиапроцессов не увеличивают число открытых файловых дескрипторов тестового процесса. Проверены наследование группы, stdin `/dev/null`, отделение stderr и восстановление SIGTERM при блокировке сигнала вызывающим потоком.
- [resource_process_checks.py](../scripts/resource_process_checks.py) запускает настоящий собранный worker и управляемый дочерний медиапроцесс, затем посылает SIGKILL только специальному тестовому родителю. После исправления оба процесса остановились за **0,012 секунды**. Все фикстуры удаляются автоматически; модели и пользовательский архив не используются.
- Настоящие комплектные FFmpeg/ffprobe и новый worker проверены на временном синтетическом WAV и повреждённом файле. Успешный WAV содержит 16 000 сэмплов mono/16 kHz; повреждённый файл отклонён. Исходники неизменны, частичных WAV не осталось.

Для повторения проверки процессов сначала получить путь через `swift build -c release --show-bin-path`, затем передать полный путь к `LocalScribeWorker` параметром `--worker` скрипта. Лог полного XCTest-прогона сохранён в `TestResults/resource-cleanup-tests.log`.

## Границы проверки

Сборка использовала имеющиеся Metal-артефакты; компилятор Metal Toolchain в среде отсутствует. Чистая сборка этим не подтверждена. Новая подписанная `.app`, TCC/микрофон и длительная работа настоящих моделей под Instruments в этой задаче не проверялись. Освобождение проверенных объектов и дескрипторов подтверждено тестами; отсутствие любых утечек внутри Core ML/MLX/SpeakerKit на многочасовых встречах не установлено. Принудительное завершение может оставить незавершённые данные; автоматически удаляются только распознанные безопасные производные файлы, а данные для восстановления сохраняются.
