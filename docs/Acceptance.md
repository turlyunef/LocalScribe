# Отчёт по приёмке LocalScribe 0.1

Состояние: **предварительная сборка; v1 не принята**. Проверено на физическом M1 / 16 GB, но установленная macOS сообщает 27.0.1, а не целевую 26. Код и `.app` не содержат демонстрационных транскрипций или фиктивных результатов моделей.

Обозначения: «проверено» — есть фактический запуск; «частично» — реализовано и/или есть ограниченный тест, но полного критерия это не доказывает; «ожидает» — не проверено.

Полная запись через UI и установленная macOS 26 требуют приёмки. |

## Надёжность

| Критерий | Состояние / основание |
|---|---|
| Потеря не более текущего 10 s фрагмента | Сборка двух завершённых CAF и исключение незавершённого фрагмента проверены тестом с точным числом сэмплов. fsync вне callback реализован. Фактический kill во время микрофонной записи и потеря питания не проверены. |
| Возобновление ASR по частям | Реализовано: SHA источника, profile hash, версия pipeline, интервалы; полные части сохраняются атомарно. Принудительное завершение во время ASR и измерение повторной работы ожидают. |
| Сбой диаризации без повторного ASR | Проверено: запуск с отсутствующей моделью дал failed/code 1, хэши готового ASR и результатов не изменились. |
| Сбой LLM сохраняет текст | Проверено: отсутствующая модель дала failed/code 1, прежние ASR, транскрипция и summary не изменились. Также реальные невалидные JSON-ответы не стали успешными итогами. |
| Один worker, отмена, повтор | Последовательный coordinator; закрытие stdin проверено: exit 72 за 0,0014 s, checkpoints неизменны. Kill всей группы дочерних процессов реализован. Стресс гонок и GUI-циклы ещё нужны. |
| Закрытие UI прекращает worker | terminate handler, EOF control channel и watchdog родителя реализованы. SIGKILL отдельного тестового родителя остановил настоящий standalone worker за 0,0065 s. Подписанная полная диагностика также закрылась без оставшегося worker. Ручное закрытие GUI во время работы ещё требует проверки. |
| Диск/память/повреждённое медиа | Preflight места, bounded capture pool, stop на critical memory pressure, атомарные файлы. Повреждённые модельные файлы не получают Ready (тест). Повреждённый контейнер и файл 10 800,001 s проверены: failed/code 1, рабочий WAV не опубликован, исходники неизменны. Противофаза проверена: предупреждение и ненулевой декодированный сигнал. Полное заполнение диска и давление памяти требуют прогона. |
| Повтор не уничтожает успешный результат | Контрактный тест проходит: activeRunId сохраняется при сбое/восстановлении; pendingRunId отдельный. UI и полная цепочка ожидают. |
| Повреждённый элемент архива | Проверено: некорректный JSON одного элемента не скрывает остальные; несовпадение UUID manifest/каталога не позволяет перезаписать соседнюю запись при восстановлении. Неизвестные версии не перезаписываются. |

## Качество и производительность

На размеченном контрольном наборе пока **не измерены** WER RU/EN/mixed, DER, ошибки имён/чисел/отрицаний, пропуски, ложные решения/задачи, владельцы/сроки, full large-v3 против Turbo. Нет обещания скорости для пользовательских записей.

Дополнительная проверка 18.10.2026, summary11: `swift test -c release -j 4 --force-resolved-versions` — 32 теста без ошибок, включая раздельное извлечение разделов, контекст RU/EN и границ частей, обязательный целевой массив ответа, основания и типографские кавычки. Использованы имеющиеся Metal-артефакты; чистая сборка без установленного Metal Toolchain этим запуском не подтверждается.

Локальная Qwen3.5-9B-4bit проверена на готовых текстах в технических прогонах. Короткая фактическая беседа сохранила три пункта обзора и пустые решения/задачи/вопросы. Контроль с русским предложением и английским подтверждением после проверки оснований сохранил одно решение о выпуске в пятницу, одну задачу отправить план завтра (speaker-1, исходный срок «завтра») и вопрос согласования бюджета. Кандидат «Давайте сделаем это» не стал отдельным решением; личное обещание осталось задачей. Проверка оснований контрольного диалога возобновлялась из сохранённых извлечений. Апостроф `let’s`, который модель возвращала как `let's`, сопоставляется с восстановлением дословной цитаты из исходника. Это узкая проверка состава итогов по тексту, без оценки распознавания, диаризации и качества длинных встреч; технические данные остаются в исключённой из Git папке TestResults.

Тринадцать тестов ядра прошли без ошибок. Отдельно цифровая тишина прошла все этапы: 0 сегментов, 0 задач, 0 решений; диаризация и LLM не запускают модели для пустой транскрипции. Это не оценка шума тихой комнаты. Короткая синтетическая речь без поручений также дала 0 задач и решений; это узкий технический контроль, не оценка ложных поручений на настоящих встречах.

Короткое синтетическое аудио — 22,244 s, два системных голоса RU/EN/RU. Первый ASR-прогон: 62,28 s и RSS 3 228 467 200 байт; диаризация 12,12 s и RSS 136 019 968 байт. Этот вариант пропустил EN и был исправлен; его скорость не выдаётся за замер окончательного конвейера. Исправленный ASR — 77,01 s, RSS 3 809 837 056 байт; диаризация — 12,40 s, RSS 148 897 792 байт. В Qwen обнаруживались пропуски EN-поручений и перенесённые/переведённые сроки; добавлены раздельное извлечение языков и консервативное обнуление неподтверждённых optional-полей. Финальный signed sandbox-прогон summary10 сохранил обе разные задачи и одно решение, объединил повторные основания, оставил неизвестные имена/сроки задач пустыми. ASR: 44,06 s, RSS 3 830 792 192 байт; диаризация: 10,47 s, RSS 162 398 208 байт; LLM: 245,78 s, RSS 3 049 259 008 байт. Это контроль конкретного синтетического примера, а не общая оценка смысловой точности. Неточный первый EN timestamp/неизвестный участник остаётся проблемным примером.

Трёхчасовой тест диаризации повторяет ту же синтетическую речь, а не тишину. Он полезен для проверки размера входа и памяти, но не представляет настоящую трёхчасовую встречу. RSS worker не равен общей памяти системы: UI, Core ML/ANE-службы, memory pressure и swap отдельно не измерены. Часть сборок выполнялась одновременно с техническими пробами; опубликованные числа не являются чистым производительным бенчмарком.

Для завершения приёмки нужны правомерные реальные записи и ручной эталон, чистый холодный запуск на macOS 26, проверка микрофона/GUI и сценариев сбоев. Каждый оставшийся пункт должен получить фактический результат, а не только отметку о наличии кода.

Пошаговый оставшийся прогон — [MacAcceptance.md](MacAcceptance.md). Машиночитаемые факты окончательной сборки — [Measurements.json](Measurements.json).

Исправление немедленной остановки в 0.1.1 и результаты настоящего микрофона: [MicrophoneFix.md](MicrophoneFix.md).

## Дополнение: сессия 6 ASR, 22.10.2026

Автоматическая оценка фактически интегрированного
`1.0.0-audio2-asr8-live1-diarization4-summary15` завершена;
**полная приёмка не пройдена**. Полный исходник 671,1 с прошёл ASR/диаризацию,
но summary15 отказал по лимиту ответа: текст/pending/checkpoint сохранены,
полные итоги не опубликованы. Заранее отложенный CAF 266,078 с: 511 ручных слов,
offline WER 34,64%, настоящий live raw 30,72%, final 30,33%. Обнаружены перевод
русских фраз, смысловые дубли и ошибочные факты/открытые вопросы в готовых итогах.
Schema/evidence-ID validation не подтверждает смысловую точность.

Реальные JSONL worker, закрытые CAF, checkpoint до seal, EOF/код 72, native
resumeRun, непрерывные 9 частей, SHA/PCM, отказы на повреждении и отсутствующих
моделях, сохранность архива и async rendering/MD/TXT прошли проверку на копиях.
Live использует полный 16 кГц PCM реальной речи; физический микрофон/native 48 кГц
и подача в реальном времени не проверены. 332 release XCTest: 0 ошибок,
8 штатных opt-in пропусков; 59 Python: 0 ошибок. Отдельные реальные модельные
регрессии завершились exit 0 с deny network. Новых production-изменений нет.

Микрофон/TCC/визуальный GUI, чистая macOS 26/Metal-сборка, перезагрузка без сети,
полный EN/mixed gold, DER/word/noise разметка, настоящая трёхчасовая встреча,
нагрузка общей памяти/питания/диска/сон в сессии 6 **не проводились**. Исторические
проверки выше не расширяются этим прогоном. Состояние, стоимость с отдельным
load и следующие действия — [ASRExperimentStatus.md](ASRExperimentStatus.md),
`TestResults/asr-acceptance-session6-20261022/findings.md` и `session-state.json`.
Текущий независимый набор использован; после настройки нужен новый материал.
