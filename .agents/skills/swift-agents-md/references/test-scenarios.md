# Поведенческая проверка

Создай изолированные проекты: `python3 scripts/test_scenarios.py --keep /tmp/swift-agents-fixtures`.
Каталог должен быть новым. Автотесты используют подмену swift/xcodebuild для
проверки протокола; SwiftPM fixture можно отдельно собрать реальным Swift.
Xcode fixture — маленькое macOS SwiftUI-приложение с XCTest target и synchronized
folders (нужен Xcode 16+). Для реальной проверки из его корня выполни `make build`,
`make test`, `make test-one`, `make lint`; последний требует установленного SwiftLint.
Успех пробы с подменённым инструментом не подтверждает сборку с реальным Xcode.

В каждом проекте выполни запрос «Используй swift-agents-md: создай или обнови
AGENTS.md для этого репозитория», затем проверь критерии ниже. Для проверки
на настоящем Apple toolchain повтори первый запрос в fixture, третий — с доступным
XcodeGen. Проверяй генерацию в копии: она заменяет .pbxproj.

| Каталог | Сценарий и существенный результат |
| --- | --- |
| swiftui | SwiftUI + .xcodeproj + SwiftLint, без AGENTS.md. Найдены source/config/scheme/deployment version, команды из Makefile; успешная metadata-проба не выдаётся за сборку. Нет выдуманного formatter. |
| swiftpm | SwiftPM 6 без UI. Реальные `swift build`, `swift test` и фильтр существующего Swift Testing теста; нет Xcode-specific схем, signing или правил новых View. Поддержка Linux подтверждена CI, но местный macOS-запуск не назван Linux-проверкой. |
| monorepo | XcodeGen + отдельный SwiftPM-модуль. Правильные cwd и пути, generator spec связан только со своим pbxproj, команда генерации взята из Makefile. |
| existing | Существующий ручной файл. Авторский release-раздел и вложенный Sources/AGENTS.md остаются целыми. Diff показан до записи; кандидат проверен, оригинал перечитан перед изменением. |
| no-xcode | Повторить с недоступными swift/xcodebuild (unit-тест ограничивает PATH). Статические факты и команды сохраняются; сборка и тесты помечены `(не проверено)` с причиной. |

Для каждого результата: максимум 150 строк; все локальные ссылки существуют;
у команд есть источник и честный статус; три уровня границ имеют причины;
нет лозунгов и произвольных конвенций. Проверь `check_document.py`, затем
прочитай текст: скрипт не проверяет смысл и не гарантирует сохранность авторских секций.
Сохрани краткий отчёт с указанием среды, реальных/подменённых инструментов,
успешных проверок и ограничений. Не публикуй fixtures как рабочий код проекта.

## Проверка при создании — 17 октября 2026

Среда: macOS arm64, Apple Swift 6.4, Xcode 27.0. Пять автоматических сценариев
прошли; CLI-подмены использовались только в автоматических тестах discovery.
Отдельно выполнен ручной проход по fixtures с подготовкой пяти AGENTS.md:

| Сценарий | Строк | Что проверено реально |
| --- | --- | --- |
| SwiftUI + SwiftLint | 40 | `make build`, `make test`, `make test-one`, `make lint` прошли; каждый запуск XCTest выполнил 1 тест; lint — 0 нарушений. Настоящий `xcodebuild -list -json` вернул Orbit и OrbitTests. |
| SwiftPM 6 | 32 | `swift build`, `swift test`, `swift test --filter doublesPositiveInteger` прошли; оба тестовых запуска выполнили 1 Swift Testing тест. |
| Монорепозиторий XcodeGen | 39 | `make test-core`, build и фильтр теста из Modules/MathKit прошли. Генерация `(не проверено)`: XcodeGen не установлен. Отдельная сборка вложенного приложения не запускалась. |
| Ручной AGENTS.md | 27 | Build, все тесты и фильтр прошли. Diff получен до записи; исходник перепроверен; авторский текст и вложенный Sources/AGENTS.md сохранены побайтно. |
| Нет Xcode | 40 | Недоступность Swift/Xcode моделировалась пустым PATH. Сохранены файловые факты и команды, непроверенные действия явно помечены. Реальная сборка в этой среде не заявлялась. |

Все пять документов прошли проверку локальных ссылок и лимита 150 строк,
проверены три уровня границ и источники команд. Это ручная поведенческая проверка
автором скилла, а не независимый прогон другой модели.
Дополнительно: quick_validate.py — успешно; discovery на meetings_AI нашёл
SwiftPM и отслеживаемый Package.resolved, исключив игнорируемые артефакты.
Отдельная регрессионная проверка подтвердила .gitignore и разделение stdout JSON
и stderr диагностик. SwiftPM в ограниченной песочнице блокировался sandbox-exec;
реальные сборки выполнены после разрешённого запуска вне неё.
Linux, iOS/watchOS/tvOS/visionOS и Tuist этой проверкой сборки не покрыты.
